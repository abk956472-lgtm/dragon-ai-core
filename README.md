# DRAGON AI CORE

DRAGON AI CORE هو نظام ذكاء اصطناعي متقدم يحتوي على محرك معالجة مركزية، محرك تعلم ذاتي، محرك تعلم من الويب، وسياسات أمان وتقييم علمي.

## المميزات
- **FastAPI**: تقديم API للخدمات والمحادثة واختبارات الأمان.
- **Knowledge Base**: محرك معرفة يدعم Supabase مع إمكانية التشغيل التلقائي في الذاكرة (in-memory fallback) في حال عدم توفر بيانات الاتصال.
- **Security Engine & Policy**: التحكم في الصلاحيات واختبار مفتاح إيقاف الطوارئ (Kill Switch).
- **Scientific Policy**: تقييم الأدلة العلمية والتمييز بين الحقائق والاستنتاجات والفرضيات.

## التشغيل وإعداد البيئة

### 1. تثبيت الاعتمادات:
```bash
pip install -r requirements.txt
```

### 2. المتغيرات البيئية:
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```bash
cp .env.example .env
```

### 3. تشغيل الخادم:
```bash
uvicorn app:app --reload
```

### 4. تشغيل الاختبارات:
```bash
python3 -m pytest
```
